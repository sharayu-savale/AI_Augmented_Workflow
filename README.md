# AI Augmented Workflow 🤖

## Project Overview

AI Augmented Workflow is a simple Python-based rule chatbot.
It interacts with users through the command line and provides
predefined responses based on keywords in the user's questions.

## Objective

The objective of this project is to understand the basic working
of a chatbot using Python, user input, conditional statements,
loops, and keyword-based responses.

## Features

- Interactive chatbot conversation
- Greeting response for "hello" and "hi"
- Chatbot name response
- Artificial Intelligence explanation
- Machine Learning explanation
- Python explanation
- Exit commands
- Default response for unknown questions

## Technologies Used

- Python 3.14.7
- Visual Studio Code
- PowerShell
- Git
- GitHub
